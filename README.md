# STM32_LOOPCONTROL_MOTOR
STM32F103 + AS5600 编码器，2804云台电机，**速度闭环V/F驱动（无电流采样，不是完整FOC）**

### 串口配置
波特率：115200，8N1
- `Rxx`：启动电机，例 `R6` → 6 rad/s
- `Txx`：运行状态下调速，例 `T3` → 3 rad/s
- `S`：安全停机，关闭驱动EN引脚，电机断电，防止持续发热
- `H`：串口握手测试

### 硬件
- MCU：STM32F103
- 编码器：AS5600 I2C
- 电机：2804 BLDC云台电机
- 供电：12V
- 驱动EN：PB9

### 注意事项
1. 无电流采样，没有软件限流保护；堵转立刻发S停机
2. S停机后不要手动拨动转子，否则R启动会抖动
